# 考后复盘本（hanlu-good）

女儿的学习轨迹跟踪与考后复盘系统。每次考试录入成绩与错题，系统自动生成各科得分率、失分归因分布，并支持错题复习规划与提分行动项管理。

## 功能

- **考试管理**：录入每次月考的科目、成绩、满分，记录考试类型与日期
- **各科得分**：按科目展示得分/满分与得分率，多场考试对比升降
- **错题本**：录入错题（题号/得失分/失分原因/知识点），标记掌握状态
- **趋势分析**：
  - 各科得分率趋势折线（≥2 次考试）
  - 最新一次各科得分率雷达图
  - 失分归因分布（知识缺漏 / 推理薄弱 / 粗心失误 / 时间不足）
  - 各科失分归因堆叠柱状图（一眼看出哪科哪种问题最重）
- **行动项**：制定可衡量的提分任务（含标准与截止日期）
- **数据备份**：导出 SQLite 数据库文件（.db）/ SQL 备份（.sql），支持导入恢复与换机迁移

## 技术栈

- Vue 3（`<script setup>`）+ TypeScript + Vite
- Tailwind CSS
- SQLite（sqlite-wasm，运行时 9 张结构化表）
- IndexedDB 持久化快照（刷新/关闭不丢失，数据本体存于 SQLite 表）
- ECharts 5.x 数据可视化

## 开发运行

```bash
npm install
npm run dev      # 启动本地开发服务（默认 http://localhost:33100）
npm run build    # 生产构建
npx vue-tsc -b   # 类型检查
```

## 数据说明

数据全部结构化存储于本地 SQLite 数据库表，并持久化到本机浏览器。关闭/刷新不丢失。如需换机器，可在「设置 → 数据备份/换机迁移」导出 `.db` 数据库文件，在新电脑导入恢复。
